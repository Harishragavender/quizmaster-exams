## 📖 Overview

An online examination and testing portal featuring timed multiple-choice quizzes, instant grading, and performance analytics.

This project was built as part of the **Web Technology Portfolio** series to demonstrate client-side web application development, interactive user interfaces, clean CSS architecture, and modern UX patterns.

---

## ✨ Key Features

- **Timed Assessments**: Configurable countdown timer with real-time warning indicators.
- **Multiple Question Categories**: Practice tests in Web Technology, Computer Science, and General Aptitude.
- **Instant Scoring & Review**: Detailed scorecard with correct answer explanations and percentage marks.
- **Progress Bar & Question Navigator**: Jump directly between questions and review flagged answers.
- **Clean Academic UI**: Distraction-free test environment with question pagination and instant submit modal.

## 🚀 Getting Started & Local Setup

### 1. Clone the repository
`ash
git clone https://github.com/Harishragavender/quizmaster-exams.git
cd quizmaster-exams
`

### 2. Run locally
Since this is a client-side web application with zero external runtime dependencies, you can run it immediately:

- **Option A (Direct)**: Double-click `index.html` to open it directly in any modern web browser (Chrome, Edge, Firefox, Safari).
- **Option B (Live Server)**: Open the folder in VS Code, right-click `index.html` and choose **"Open with Live Server"**.
- **Option C (Python local server)**:
  `ash
  python -m http.server 8000
  `
  Then visit http://localhost:8000.
